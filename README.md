Documentação da Atividade
Objetivo

O objetivo desta atividade foi praticar comandos básicos do terminal Linux, criação de arquivos, permissões de execução e execução de scripts em Shell e Python.

Etapas realizadas
1. Criação do diretório

Foi criado um diretório chamado calc dentro da pasta modulo1 utilizando o comando:

mkdir /home/gabriel/modulo1/calc

Esse diretório será utilizado para armazenar os arquivos da atividade.

2. Navegação entre diretórios

Foram utilizados comandos como:

ls para listar os arquivos existentes.
cd para acessar outros diretórios.
ll para visualizar detalhes dos arquivos.

Esses comandos permitiram navegar pela estrutura de pastas do projeto.

3. Tentativas de execução

Durante a atividade foram feitas algumas tentativas de executar comandos e arquivos que ainda não existiam, como:

calc

e

nano_calculadora.sh

Essas mensagens de erro fazem parte do processo de aprendizado, indicando que o comando ou arquivo ainda não estava disponível.

4. Criação do script Shell

Foi criado o arquivo:

calculadora.sh

utilizando o editor Nano.

Depois foi concedida permissão de execução com:

chmod +x calculadora.sh

Em seguida o script foi executado com:

./calculadora.sh

O script exibiu mensagens de início e fim da execução e mostrou o diretório atual.

5. Criação do programa em Python

Foi criado o arquivo:

calculador.py

O programa foi executado utilizando:

python3 calculador.py
6. Execução do programa

Durante a execução, o programa solicitou:

Nome do usuário;
Dois valores para realizar uma soma;
Dois valores para realizar uma subtração;
Dois valores para realizar uma multiplicação;
Dois valores para realizar uma divisão.

Após cada operação, o resultado foi exibido na tela.

O programa também utilizou estruturas condicionais (if e else) para verificar:

Se a soma era maior que 10;
Se a multiplicação era maior que 100;
Se o resultado da divisão era maior ou menor que o valor definido na condição.
Conclusão

Com esta atividade foi possível praticar:

Criação e navegação de diretórios no Linux;
Utilização dos comandos mkdir, ls, cd, ll e chmod;
Criação de arquivos utilizando o editor Nano;
Execução de scripts Shell;
Execução de programas em Python pelo terminal;
Entrada e saída de dados;
Operações matemáticas;
Estruturas condicionais (if e else).

A atividade permitiu integrar conhecimentos de Linux e Python, demonstrando o funcionamento de um programa simples executado diretamente pelo terminal.
