Calculadora Básica em Python
Descrição

Este projeto foi desenvolvido para praticar os conceitos básicos da linguagem Python.

O programa solicita o nome do usuário e realiza as seguintes operações matemáticas:

Soma
Subtração
Multiplicação
Divisão

Ao final de algumas operações, o programa utiliza estruturas condicionais (if e else) para verificar se o resultado atende a determinada condição e exibe uma mensagem na tela.

Conceitos utilizados
Variáveis
input() para receber dados do usuário
print() para exibir informações
Conversão de dados com int()
Operadores matemáticos (+, -, *, /)
Estruturas condicionais (if e else)
Como executar
Salve o código em um arquivo com extensão .py.
Abra o terminal na pasta onde o arquivo está salvo.
Execute o comando:
python nome_do_arquivo.py
